Jaringan Komputer & Internet

Dari Wi-Fi rumah sampai BTS 5G — pelajari cara perangkat saling terhubung, bagaimana data mengalir, dan cara melindungi diri saat online.

Analogi: Jaringan sebagai Sistem Jalan Raya

Bayangkan LAN seperti kompleks perumahan — jalan kecil yang menghubungkan rumah-rumah tetangga. Internet seperti jalan tol nasional yang menghubungkan semua kompleks se-Indonesia. Router adalah gerbang tol, Switch adalah pertigaan di dalam kompleks, dan IP Address adalah alamat rumah Anda.

LAN vs Internet

  • LAN (Local Area Network): jaringan lokal di satu gedung/ruangan. Cakupan kecil, cepat, dikelola sendiri.
  • Internet: jaringan global antar-jaringan (interconnected network) yang menghubungkan miliaran perangkat dengan protokol TCP/IP.
  • LAN bisa terhubung ke internet melalui router + modem ISP.
CONTOH SEHARI-HARI

LAN: HP, laptop, dan Smart TV di rumah Anda terhubung ke Wi-Fi yang sama — bisa saling kirim file via AirDrop/ShareIt tanpa internet.
Internet: Saat Anda scroll TikTok, buka WhatsApp, atau nonton YouTube — data menyeberang ke server di luar negeri.

Pengalamatan IP

IP Private (Lokal)

Dipakai di jaringan lokal. Contoh: 192.168.x.x, 10.x.x.x, 172.16–31.x.x. Tidak bisa diakses langsung dari internet.

IP Public (Global)

Alamat unik yang bisa diakses dari internet. Diberikan oleh ISP ke router/modem Anda.

CONTOH SEHARI-HARI

IP Private seperti nomor kamar di asrama — hanya dikenal di dalam asrama (mis. kamar 192.168.1.5). IP Public seperti alamat gedung asrama di Google Maps — bisa ditemukan siapa pun di dunia (mis. 103.47.132.10). Saat Anda kirim paket dari kamar, satpam (router/NAT) mencatat "dari asrama X" agar balasan kembali ke kamar yang benar.

Fungsi Router & Switch

Router

Menghubungkan jaringan berbeda (LAN ↔ Internet), mengarahkan paket data antar jaringan, dan melakukan NAT (menerjemahkan IP private ke IP public).

Switch

Menghubungkan banyak perangkat dalam satu LAN, meneruskan data berdasarkan alamat MAC, dan mengatur lalu lintas dalam jaringan lokal.

CONTOH SEHARI-HARI

Router: Kotak putih IndiHome di ruang tamu Anda — dialah yang menyambungkan HP Anda ke internet IndiHome. Switch: Kalau Anda pasang 4 laptop di lab komputer dengan satu kabel ke dinding, biasanya ada switch kecil di balik meja untuk membagi koneksi ke 4 laptop tersebut.

Jenis Jaringan Berdasarkan Jangkauan

PAN

Personal Area Network — ±10 m. Contoh: Bluetooth HP ke earbuds, Smart Watch ke HP.

LAN

Local Area Network — 1 gedung. Contoh: Wi-Fi rumah, jaringan lab sekolah.

MAN

Metropolitan Area Network — 1 kota. Contoh: Jaringan antar-cabang bank di Surabaya.

WAN

Wide Area Network — antar-negara. Contoh: Internet, jaringan kantor pusat-cabang lintas negara.

Analogi: BTS sebagai Menara Pemandu

Bayangkan BTS (Base Transceiver Station) seperti menara mercusuar di pelabuhan. HP Anda adalah kapal yang memancarkan sinyal "Halo, saya di sini!" ke mercusuar terdekat. Mercusuar meneruskan pesan Anda ke kantor pusat (operator), lalu ke tujuan akhir. Jika banyak kapal di pelabuhan yang sama, lalu lintas bisa padat — meski sinyal mercusuar tetap kuat.

Transmisi Data Seluler (3G/4G/5G)

Ponsel Anda mengirim/menerima data melalui gelombang radio ke BTS terdekat. BTS terhubung ke jaringan operator, lalu ke internet.

Wi-Fi

Koneksi nirkabel lokal via Access Point. Cakupan puluhan meter, cepat, cocok untuk rumah/kantor. Tidak memakai kuota seluler.

CONTOH

Nonton film di rumah lewat Wi-Fi IndiHome — hemat kuota HP, lebih stabil, tapi terbatas jangkauan rumah.

Bluetooth

Koneksi jarak sangat dekat (~10 m) untuk perangkat pribadi: earphone, keyboard, transfer file kecil. Hemat daya.

CONTOH

Dengar lagu pakai TWS earbuds, atau share foto via ShareIt ke teman meja sebelah.

Tethering / Hotspot

Membagikan koneksi seluler ponsel ke perangkat lain (laptop, tablet) melalui Wi-Fi/Bluetooth/USB.

CONTOH

Di kelas saat Wi-Fi sekolah mati, guru mengaktifkan hotspot HP agar laptop bisa tampilkan presentasi.

Fakta Menarik Seputar Sinyal HP

Bar sinyal mengukur kekuatan koneksi HP ↔ BTS, bukan kecepatan. Jika banyak pengguna berbagi satu BTS, bandwidth dibagi-bagi seperti jalan tol yang macet meski Anda sudah di jalur tol.
Gelombang radio sulit menembus beton tebal dan logam. Itulah sebabnya operator memasang "repeater" sinyal di gedung-gedung besar, atau Anda harus naik ke lantai atas.
5G butuh BTS lebih rapat (jarak lebih pendek) dan infrastruktur fiber optic ke setiap BTS. Saat ini baru tersedia di kota-kota besar. Di daerah rural, 4G masih jadi andalan.

Analogi: HTTPS sebagai Amplop Tertutup

HTTP seperti mengirim kartu pos — siapa pun yang memegangnya (operator, penyadap Wi-Fi) bisa membaca isinya. HTTPS seperti mengirim surat dalam amplop tersegel — kurir hanya tahu alamat tujuan, tapi tidak bisa membaca isi surat. Ikon 🔒 di address bar menandakan amplop itu tersegel rapi.

Enkripsi: HTTP vs HTTPS

HTTP

Data dikirim tanpa enkripsi. Bisa disadap di Wi-Fi publik. Jangan masukkan password/data pribadi di situs HTTP!

HTTPS

Data terenkripsi via TLS/SSL. Meski disadap, isi data tidak terbaca. Selalu cek ikon gembok 🔒 di address bar.

CONTOH SEHARI-HARI

Saat Anda login Instagram, lihat address bar — ada https:// dan ikon gembok. Jika sebuah link WhatsApp mengarah ke http:// tanpa gembok dan meminta password, itu tanda bahaya. Tutup segera!

MitM Attack

Penyerang di Wi-Fi publik menyadap komunikasi Anda. Hindari login bank/akun penting di Wi-Fi gratisan.

CONTOH

Anda login M-Banking di Wi-Fi kafe. Penyadap yang duduk di meja sebelah bisa merekam password Anda jika situsnya HTTP.

Phishing

Tautan/situs palsu yang menipu Anda agar menyerahkan data. Cek URL dengan teliti sebelum login.

CONTOH

SMS "Selamat! Anda menang iPhone, klaim di bit.ly/xxx" — link itu mengarah ke situs palsu yang meminta data kartu kredit.

Password & 2FA

Gunakan password panjang + unik per akun, dan aktifkan 2FA (autentikasi dua faktor) untuk keamanan berlapis.

CONTOH

Login Instagram pakai password + kode OTP WhatsApp = 2FA. Walau password bocor, penyerang tetap butuh OTP di HP Anda.

5 Kebiasaan Digital Aman (Sehari-hari)

  1. 1Cek gembok 🔒 sebelum memasukkan password — terutama di M-Banking, email, marketplace.
  2. 2Aktifkan 2FA di semua akun penting (WhatsApp, Instagram, email, bank).
  3. 3Jangan klik link sembarangan dari SMS/WhatsApp — meski dari nomor yang terlihat resmi.
  4. 4Ganti password jika menduga akun bocor — dan jangan pakai password sama untuk banyak akun.
  5. 5Hindari transaksi bank di Wi-Fi publik gratis (bandara, kafe, mal). Gunakan data seluler sendiri.

Lembar Kerja Peserta Didik

Aktivitas mandiri/kelompok untuk menerapkan konsep jaringan & internet pada perangkat Anda sendiri.

Identitas

Aktivitas 1 — Cek IP Address Perangkat

Langkah: Buka Pengaturan → Wi-Fi → Ketuk nama Wi-Fi Anda → Lihat detail di HP Android, atau Settings → Network → Wi-Fi → Details di iPhone. Atau kunjungi whatismyip.com untuk melihat IP Public.

Pertanyaan: Tuliskan IP Private & IP Public perangkat Anda, lalu bandingkan dengan teman semeja — apakah sama atau berbeda? Mengapa?

Aktivitas 2 — Uji URL HTTP vs HTTPS

Langkah: Kunjungi salah satu situs yang Anda sering buka (mis. instagram.com, tokopedia.com). Perhatikan ikon gembok 🔒 di address bar. Lalu coba kunjungi http://neverssl.com sebagai contoh situs HTTP murni.

Pertanyaan: Apa perbedaan yang Anda lihat? Apakah Anda akan memasukkan password di situs HTTP? Mengapa?

Aktivitas 3 — Analisis Skenario Sehari-hari

Bacalah skenario berikut, lalu tuliskan analisis Anda.
